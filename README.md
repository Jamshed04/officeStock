Представлен готовый вариант дообученной нейронной сети на основе BERT (https://huggingface.co/cointegrated/rubert-tiny2)

Весь код, который необходимо брать находится в test_folder. Там содержатся 4 основных обязательных компонента:
  1) ml_data - веса модели в формате .onnx и токенайзер
  2) category_table.csv - таблица категорий товаров
  3) predict_data.py - основной код, содержащий всю логику, сводящаяся к вызову одной функции
  4) 1.py - тренировочный простой пример для работы с сеткой (подвавать на вход всегда надо список строк, даже если она одна)

requirements.txt в проекте представляет собой необходимые бибилотеки для работы предсказания. Они минимизированы для дальнейшего развертывания, библиотеки для разработки (torch и тд) убраны за ненадобностью.
